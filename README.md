# Tele_Care
Tele_Care est une application d’assistance à domicile pour personnes âgées, basée sur une architecture microservices. Elle permet de déclencher une alerte d’urgence, de récupérer automatiquement le dossier du bénéficiaire et ses contacts d’urgence, puis d’affecter une intervention à un assistant d’astreinte. L’urgence est clôturée après l’intervention avec un compte-rendu.
